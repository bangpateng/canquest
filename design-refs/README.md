# Folder Referensi UI (Pinterest Screenshots)

Taruh semua screenshot template dari Pinterest di folder ini.

## Tips penamaan file (opsional tapi membantu)
Beri nama sesuai halaman yang mau diterapkan, contoh:
- `01-overview.jpg` → halaman Overview/Dashboard
- `02-quests.jpg` → halaman Quests
- `03-earn.jpg` → halaman Earn/Campaign
- `04-wallet.jpg` → halaman Wallet
- `05-leaderboard.jpg` → halaman Leaderboard
- `06-global.jpg` → gaya umum (navbar, sidebar, kartu, warna)

Kalau tidak dinamai pun tidak apa-apa — saya akan lihat semua gambar
dan yang cocok dengan halaman mana, lalu saya konfirmasi dulu
pemetaannya sebelum mulai mengubah kode.

## Format yang didukung
PNG, JPG, JPEG. Boleh lebih dari satu screenshot per halaman.
